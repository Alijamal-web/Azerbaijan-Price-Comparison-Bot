# Azerbaijan Price Comparison Bot

A Telegram bot designed to help users compare electronic product prices across popular stores in Azerbaijan.

## Features

- Browse products by category.
- Compare prices from Kontakt Home, Baku Electronics, and Irshad.
- View store links for each product.
- Automatically identify the lowest listed price.
- Simple and user-friendly Telegram interface.

## Categories

- Smartphones
- Computers and Laptops
- Tablets
- Headphones

## Technologies Used

- Python
- Telegram Bot API
- pyTelegramBotAPI

## Installation

1. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

2. Run the bot:

   ```bash
   python main.py
   ```

## How It Works

Users select a product category and choose a specific product. The bot displays available store offers, their listed prices, and links. It also identifies the store with the lowest listed price.

## Future Improvements

- Real-time price collection through web scraping.
- Automatic price updates.
- More supported electronics stores.
